# Teras Lab. RESHAPE 設定手順

## 1. 裏側のプログラム（Apps Script）
1. https://script.google.com を開き「新しいプロジェクト」。名前を「RESHAPE」にする
2. 最初からある `コード.gs` の中身を全部消して、`gas/Code.gs` の中身を全部貼り付けて保存
3. 上の関数の選択で `setup` を選び「実行」→ 許可の画面で自分のGoogleアカウントを選び「許可」
   - 運営用シートにプルダウンと「毎日のストレッチ」タブ、ドライブに「RESHAPE_会員の写真」フォルダができます
4. 左の歯車（プロジェクトの設定）→ 一番下「スクリプト プロパティ」で次の3つに値を入れる
   - `LINE_CHANNEL_ID`：手順2で作るLINEログインのチャネルID（数字）
   - `ADMIN_KEY`：管理者ページの合言葉（自分で決める）
   - `ANTHROPIC_API_KEY`：食事サポートのAIキー（なければ空欄のままでOK。食事サポートだけ「準備中」になります）
5. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：自分 ／ アクセスできるユーザー：全員
   - 「デプロイ」→ 表示された「ウェブアプリのURL」（…/exec）を控える

## 2. LINEログイン（LINE Developers）
1. https://developers.line.biz/console/ に、RESHAPE用の公式LINEと同じLINEアカウントでログイン
2. 公式LINEと同じプロバイダーを開き「新規チャネル作成」→「LINEログイン」
   - チャネル名：Teras Lab. RESHAPE ／ アプリタイプ：ウェブアプリ
3. 作成したチャネルの「チャネル基本設定」にある **チャネルID** を控える（1-4 に入れる）
4. 「LIFF」タブ →「追加」
   - LIFFアプリ名：RESHAPE ／ サイズ：Full
   - エンドポイントURL：`https://kazuhiko125910.github.io/teras-lab/reshape/`
   - Scope：`openid` と `profile` にチェック ／ 友だち追加オプション：On（Normal）
5. 作成後に表示される **LIFF ID** を控える
6. チャネルを「公開済み」にする（開発中のままだと本人以外ログインできません）

## 新しい会員が入ったとき
1. 会員がリッチメニューからサイトを開くと、会員シートに「承認待ち」で自動登録され、目標設定ワークが始まります
2. 加藤さんが会員シートでその人の行に「プラン」「支払日」「開始日」を入れ、「利用」を「利用中」にする
3. 次に開いたときから毎日の画面が表示されます

動画やロードマップを直したときは、最大10分でサイトに反映されます（すぐ反映したいときは Apps Script で `clearCache` を実行）。

## 毎月の中間目標と見直し
- 目標設定ワークで、6ヶ月後の目標と「毎月の中間目標」（自動計算→本人が調整）を決める
- 開始日から1ヶ月ごとが見直しの日。サイトの「今日」に見直しカードが出る（`?v=review` でも開ける）
- 見直しの内容は「月の目標」タブに記録（中間目標・実績・達成数・ふり返り3問）
- 6ヶ月ごとに最終見直し → 次の6ヶ月（第2期…）の目標と中間目標を決める
- LINEへの自動リマインド：毎朝9時に `monthlyReminder` が動き、見直しの日を迎えた会員（利用中・卒業生）に送信
  - スクリプトプロパティ `LINE_MESSAGING_TOKEN` に、Messaging APIチャネルの長期チャネルアクセストークンを入れる
  - 動作確認：会員シートの自分の行の「メモ」に「テスト送信」と書いて `testPush` を実行

## 契約書に合わせた運用（2026年9月〜）
受講契約書（第5条・第9条・第10条）の内容にサイトを合わせました。

### 更新のしかた（1回だけ）
1. Apps Script の `コード.gs` の中身を全部消して、`gas/Code.gs`（日本語がうまく貼れないときは `gas/Code_ascii.gs`）を貼り付けて保存
2. 関数 `setup` を実行（会員シートに新しい列、「目標の履歴」タブ、プルダウンが追加されます）
3. 「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン」を「新しいバージョン」にして「デプロイ」
   - 「新しいデプロイ」ではなく「デプロイを管理」から更新すると、ウェブアプリのURLが変わらず、config.js を直す必要がありません

### 目標の確認（第5条）
- 会員が目標を決めたり数字を変えたりすると、会員シートの「目標の確認」が「確認待ち」になり、「目標の履歴」タブに変更前後の目標と日付が残ります
- 管理者ページで会員を開き、「確定する」「見直しをお願い」「面談で相談」のどれかを押します（「目標の確認」で絞り込めます）
  - ひとことを入れて押すと、会員の画面の「担当からひとこと」にも表示されます
  - 「見直しをお願い」：会員の画面に「目標を見直す」ボタンが出ます
  - 「面談で相談」：STANDARDで、目標を一緒に決めるオンライン面談が必要なときに使います
- 延長保証の判定には、判定期間の終了日の4週間前までに「確定」した目標を使います

### 延長保証（第9条）
- 「記録した日」は、ストレッチかトレーニングにチェックを入れて、その日のうちに保存した日です。日付をまたいで開いたままの画面からは保存できません
- 記録の条件（STANDARD：13週のうち11週以上、VIP：26週のうち22週以上、いずれも週3日以上）を満たした人には、判定期間が終わった翌日から7日間、会員の画面に「延長保証の測定」が出ます
- 会員が測定値を送ると、会員シートの「延長保証 測定日・測定値・記録週数・判定」に結果が入ります。管理者ページでも見られます
- 判定が「対象」なら、会員シートの「延長希望」を「延長する」にして、7日以内に公式LINEで結果を伝えてください
- 病気などでサポートを一時停止した場合は、会員シートの「開始日」を停止した日数分うしろにずらしてください（判定期間もずれます）
- システムの不具合で記録できなかった日があれば、その日の記録を会員シートの「毎日の記録」に手で追加してください

### 受講期間が終わったあと（第10条）
- 受講期間は支払日から6ヶ月（VIPで延長した場合は9ヶ月）です。過ぎると、会員の画面は「受講期間が終了しました」の案内だけになります
- 卒業生コミュニティに参加した人は、会員シートの「利用」を「卒業生」にしてください。そのまま会員サイトを使い続けられます
  - 今日のおまかせ（ストレッチ2本・トレーニング1本をランダムに表示。「ほかの動画にする」で入れ替え）、部位から選ぶ動画、日々の記録、目標の変化の確認、毎月の見直し、食事サポート（写真へのフィードバックつき）
  - 受講期間中の記録と目標の履歴は、そのまま引き継がれます
- 卒業生コミュニティをやめた人は「利用」を「終了」にしてください

## Slackへのお知らせ（2026年10月〜）
次の3つがSlackに届きます。
- 会員が目標を保存したとき（初回・数値の変更・次の期）：名前、プラン、目標、管理者ページへのリンク
- 延長保証の測定値が届いたとき：測定値、記録週数、判定
- 毎朝9時：LINE登録日から3日たっても目標が未記入の人（7日目にもう一度）。名前、LINE登録日、送信用メッセージつき

### 準備
1. Slackの通知用URL（Incoming Webhook）を発行し、スクリプトプロパティ `SLACK_WEBHOOK_URL` に貼る
2. Apps Script で `setup` を実行（新しい列と、毎朝9時の `goalReminder` が追加されます）
3. `testSlack` を実行して、Slackにテスト通知が届くか確認
4. 「デプロイを管理」→ 鉛筆マーク →「新しいバージョン」でデプロイ

### LINE登録日を自動で残す（公式LINEのWebhook）
友だち追加した日に会員シートへ「承認待ち」で登録され、「LINE登録日」が入ります（サイトをまだ開いていない人も把握できます）。
1. LINE Official Account Manager（Teras Lab.RESHAPE）→ 右上「設定」→「Messaging API」→ Webhook URL に、ウェブアプリのURL（…/exec）を入れて保存
2. 「応答設定」→「Webhook」をオン（チャットはオンのままで大丈夫です）
3. 確認：自分のLINEで RESHAPE の公式LINEをブロック → ブロック解除すると、会員シートに自分の行と LINE登録日 が入ります
Webhookを設定する前に友だち追加した人は、初めてサイトを開いた日が LINE登録日 になります。

## サポート終了のお知らせ（2026年10月〜）
毎朝9時に `supportReminder` が動き、サポート終了日（STANDARD：チャット3ヶ月、VIP：6ヶ月。延長保証で+3ヶ月）に合わせて、送信用メッセージつきでSlackに届きます。
- 30日前：ラスト1ヶ月の声かけと、延長保証の条件（最後の4週間すべて週3日以上でも対象）
- 7日前：卒業生コミュニティの案内。参加の意思を確認したら、会員シートの「卒業生コミュニティ参加希望」を「参加する／参加しない」に
- 当日：終了のごあいさつ（延長保証の判定待ちの人には測定値の入力案内）
- 参加する人：サポートは終了日の月末まで続き、月末を過ぎると「利用」を「卒業生」に切り替えるよう知らせます（コミュニティの決済は毎月1日）
送った記録は会員シートの「終了案内 30日前／7日前／当日／切り替え」列に日付で残ります。
初回だけ `setup` を実行してください（列と毎朝9時の実行が追加されます）。

## サポート期限なしの会員（0期生など）
会員シートの「サポート期限」を「なし」にすると、その人は期限なしで使えます。
- 会員サイトにサポート期間・延長保証の表示が出ず、受講期間の終了もありません
- サポート終了のお知らせ（30日前・7日前・当日）も届きません
- 「延長希望」は空欄に戻してください
